COMPILAR O TVmakina PARA WINDOWS COM O GITHUB ACTIONS
=====================================================

O workflow que compila o TVmakina (instalador + versao portatil, 64 e 32 bits)
esta guardado aqui:

    tvmakina/build/tvmakina-windows.yml

Ele NAO esta em .github/workflows/ de proposito: o GitHub recusa pushes que
criem ou alterem ficheiros em .github/workflows/ quando a ligacao e feita por
uma aplicacao OAuth (e exactamente o caso deste ambiente de trabalho). Por isso
o ficheiro tem de ser colocado la por si, uma unica vez.


ACTIVAR (2 minutos, uma vez so)
-------------------------------
Opcao 1 - pelo site do GitHub
  1. Abra o repositorio no GitHub.
  2. "Add file" > "Create new file".
  3. No campo do nome escreva exactamente:
        .github/workflows/tvmakina-windows.yml
     (ao escrever as barras o GitHub cria as pastas sozinho)
  4. Cole o conteudo de tvmakina/build/tvmakina-windows.yml.
  5. "Commit changes".

Opcao 2 - pelo git no seu PC
     cd demos
     mkdir -p .github/workflows
     cp tvmakina/build/tvmakina-windows.yml .github/workflows/
     git add .github/workflows/tvmakina-windows.yml
     git commit -m "Activar a compilacao do TVmakina"
     git push


USAR
----
  GitHub > separador Actions > "Compilar TVmakina" > "Run workflow"

  No fim, em Artifacts:
    TVmakina-Windows7  ->  TVmakina-Setup-1.0.0-x64.exe
                           TVmakina-Setup-1.0.0-ia32.exe
                           TVmakina-Portatil-1.0.0-x64.exe
                           TVmakina-Portatil-1.0.0-ia32.exe
    TVmakina-browser   ->  dist/TVmakina.html
                           dist/TVmakina-completo.html

O workflow faz primeiro a verificacao (ES5 + 56 testes + ficheiro unico) num
runner Linux, e so depois compila os EXE num runner windows-2022.


SE PREFERIR NAO USAR O GITHUB
-----------------------------
Num PC com Node.js: duplo clique em tvmakina/BUILD-WINDOWS.bat.
Faz exactamente o mesmo, mas localmente.

E se nao quiser compilar nada: use tvmakina/dist/TVmakina-completo.html,
que abre com duplo clique no browser e nao precisa de instalacao.
